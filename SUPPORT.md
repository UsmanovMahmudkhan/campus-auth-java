# Support

## Getting Help

For general questions, open a GitHub issue with enough detail for someone to reproduce or understand the problem.

Good support requests include:

- Project version, such as `0.2.7`.
- Java and Maven versions.
- Operating system.
- Command or API call used.
- Sanitized output or error message.
- The authenticator method involved, if known.

## Before Opening an Issue

- Read the [README](README.md).
- Check the [documentation website](https://campus-auth-java.netlify.app).
- Search existing issues and releases.
- Run `mvn clean package` to confirm the project builds locally.

## Security Issues

Do not post sensitive security issues publicly. Follow [SECURITY.md](SECURITY.md).

## Scope

This project can help with library usage, documentation, build issues, and authorized test workflows. It cannot help with unauthorized access, credential misuse, bypassing platform controls, or activity that violates laws, platform rules, or third-party rights.
